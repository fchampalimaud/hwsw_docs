# User Control

---

The olfactometer provides diverse control and configuration options that can be selected depending on the experimental requirements and user preferences: 

- A user-friendly, open source, multi-platform, custom-designed graphic user interface (GUI) was developed in order to ease the olfactometer configuration.

- For the software based-control, the Harp Olfactometer settings and variables can be configured using [Bonsai](https://bonsai-rx.org/).

- Additionally, the valves control can be achieved with external TTLs.
