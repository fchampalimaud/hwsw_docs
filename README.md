# Website

This website is built using [Docusaurus](https://docusaurus.io/), a modern static website generator.

## Site Structure

The site documents several devices. Each device has its own folder under `docs/`,
its own sidebar and its own entry on the homepage index:

```
docs/
├── olfactometer/       # Harp Olfactometer (published)
├── flypad-controller/  # Harp Flypad Controller (placeholder)
└── current-driver/     # Harp Current Driver (placeholder)
```

The homepage (`src/pages/index.tsx`) lists the devices as cards, and the navbar
"Devices" dropdown and the footer are generated from the same list.

### Adding a New Device

1. Create `docs/<device-id>/` with at least an `overview.md` (use one of the
   placeholder devices as a template).
2. Add a sidebar for that folder in `sidebars.ts`:

   ```ts
   myDeviceSidebar: [{type: 'autogenerated', dirName: '<device-id>'}],
   ```

3. Add an entry to `src/data/devices.ts`. This single entry feeds the homepage
   card, the navbar dropdown and the footer links.

Device specific static assets (images, diagrams) go under `static/<device-id>/`
and are referenced with `useBaseUrl('/<device-id>/<file>')`.

## Pre-requisites

The recommendation is to use a Node.js version Manager like `nvm`. The official nvm is only available for Linux and macOS, but there is a Windows version called `nvm-windows`.

### nvm

*Linux and macOS*

The nvm installation script is available at [nvm-sh/nvm](https://github.com/nvm-sh/nvm?tab=readme-ov-file#installing-and-updating). You can install nvm by running the following command:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
```

*Windows*

Download and run the installer from the [nvm-windows](https://github.com/coreybutler/nvm-windows/releases) releases page. After installation, open a new Powershell window

> [!WARNING]  
> Development on Windows is usually slower than on Linux or macOS. This affects the performance of the local development server.

#### Installing Node.js (LTS) with nvm (works on Linux, macOS, and Windows)

```bash
nvm install lts
```

This command should install the latest LTS version of Node.js.

On the root of the project, you now need to indicate that you want to use the version of Node.js that you just installed:

```bash
nvm use lts
```

### Local Development

First, we need to install the project's dependencies (only needed once):

```bash
npm install
```

Then, we can start the local development server:

```bash
npm run start
```

This command starts a local development server and opens up a browser window. Most changes are reflected live without having to restart the server.

### Deployment

Any commit to the `main` branch will trigger a GitHub Action that builds the website and pushes the changes to the `gh-pages` branch. The website is hosted on GitHub Pages.

The recommended way is to use commit changes to develop in a feature branch and then merge to `main` when the feature is ready.
